# 多 Agent 协同运营自动化系统

一个可直接运行的前端项目，用于展示多 Agent 协同完成运营自动化闭环的能力：策略拆解、数据分析、执行编排、风险审校、日志追踪和指标面板。

## 项目说明

### 核心痛点

- 运营任务分散在策略、数据、执行和审核多个环节，人工切换成本高，容易出现信息丢失和响应延迟。
- 常见运营动作依赖经验判断，缺少统一编排和可追踪闭环，导致协作效率低、复盘困难。
- 临时活动、异常排障和私域转化等场景需要快速决策，但单一工具很难同时兼顾分析、执行和风控。

### 核心逻辑流

- 任务进入后先由策略规划 Agent 拆解目标，形成可执行步骤。
- 数据分析 Agent 读取指标、识别波动、补充风险信号。
- 执行运营 Agent 根据分析结果落地动作，完成内容更新、触达和参数调整。
- 审校风控 Agent 复核结果，输出回滚建议和复盘结论，形成完整闭环。
- 当前项目使用的是多 Agent 协作的演示流程，重点展示编排逻辑、状态流转和执行日志，而不是长链推理。

### 功能完善点

- 支持场景切换、重新编排、终止执行和重置看板，适合演示完整运行链路。
- 增加了进度条、阶段状态和实时日志，便于观察每个 Agent 的协同过程。
- 不同场景会输出对应的痛点、目标、关键步骤和成功信号，增强项目表达的业务针对性。

## 能力

- 场景切换：投放优化、私域转化、运营排障
- 多 Agent 协同：策略、分析、执行、审校四个角色联动
- 执行可视化：状态、流程、日志、指标一屏展示
- 现代 UI：暗色渐变、卡片化面板、响应式布局
